# Corporate Sales Record Cleaner
## Automated Data Sanitization Pipeline

### Project Overview
This project cleans a raw sales dataset using Python and Pandas.

### Technologies Used
- Python
- Pandas
- NumPy
- Google Colab


### Before and After Dimensions
- Original dataset shape: (17000, 9)
- Cleaned dataset shape: (17000, 9)

### Data Quality Results
- Duplicate rows in original dataset: 0
- Duplicate rows after cleaning: 0
- Missing values after cleaning: 0

### Project Files
- raw_sales.csv: Original uncleaned dataset.
- cleaned_sales.csv: Sanitized dataset.
- numerical_summary.csv: Numerical descriptive statistics.
- categorical_summary.csv: Categorical descriptive statistics.
- sales_record_cleaner.ipynb: Google Colab notebook.

### How to Run
Open the notebook in Google Colab and run each cell from top to bottom.
